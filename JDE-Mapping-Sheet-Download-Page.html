JDE Mapping Sheet

Turn any JSON payload into a JD Edwards field mapping sheet, right in your browser. No installation, no sign-up.

Mapping a third-party JSON payload to JDE usually means retyping every field into Excel. JDE Mapping Sheet reads the payload for you and gives you one row per field. You add the JDE table, alias, description and logic, then copy the finished sheet into Excel.

Download JDE-Mapping-Sheet.html

Single file. Open it in Chrome, Edge or Firefox.

Features

One row per JSON field

Paste or upload a payload. Each field gets a row with its full path, data type and sample value. Nested objects and arrays are handled.

Mapping columns

Add the JDE table, JDE alias, description and logic or remarks on the same row. A progress bar shows how many fields are mapped.

Map to your Excel data

Upload an Excel or CSV file and it appears with all your own columns plus a JSON path column. Drag a payload field onto a row to fill in the path.

Paths ready for scripts

Paths look like /invoicePeriod/startDate, with arrays as /lines[*]/itemNumber. This makes it easy to write Groovy scripts from your mapping.

Built for large sheets

Sort and filter every column, resize columns, drag columns into a new order and let long text wrap. An automatic # column restores the original order.

Copy to Excel

Copy the whole sheet and paste it straight into Excel. Your original columns come back with the JSON path, type, sample value and remarks added.

Clear buttons

Each section can be cleared on its own, and Reset all wipes everything. Clear buttons ask for a second click so nothing is lost by accident.

Your data stays with you

Everything runs in your browser. Your payload and mappings are not uploaded to any server. Your work is saved in the browser you use.

How to use it

Option A: Build a mapping sheet from scratch

  1. Open the file in Chrome, Edge or Firefox.
  2. In the Payload box, paste your JSON or click Upload .json. Click Format to tidy it.
  3. Stay on the Build mapping sheet tab. Every field is now a row.
  4. Fill in JDE table, JDE alias, Description and Logic / remarks for each row.
  5. Use the filters under the headings to find rows, for example Unmapped in the Mapped column.
  6. Click Copy for Excel and paste into a spreadsheet.

Option B: Map to a field list you already have

  1. Load your JSON payload as in Option A.
  2. Open the Map to existing Excel data tab.
  3. Click Upload Excel or CSV, with column headings in the first row. You can also paste rows copied from Excel.
  4. Drag each payload field from the left list onto the matching row. On a touch screen, tap the field, then tap the row.
  5. Add remarks if needed, then click Copy for Excel.

Tips

  • On the first tab, type a JDE alias that exists in your uploaded Excel data and the table and description fill in automatically. Your sheet needs headings that contain "table", "alias" and "description".
  • Pasting an exported sheet back into the second tab later restores your mappings.
  • Click the # heading to get back to the original row order after sorting.
  • Drag the grip (⋮⋮) on a heading to move a column. Drag the edge of a heading to resize it, and double-click the edge to reset it.
  • Use Reset view to restore column order, widths, sort and filters without touching your mappings.

Requirements

  • A current desktop version of Chrome, Edge or Firefox.
  • An internet connection when you open the file, because it loads its fonts and Excel reader online. Without a connection, CSV upload and pasted rows still work, but .xlsx upload does not.
  • Moving columns needs a mouse. On touch screens, sorting, filtering and tap-to-map still work.
  • The page cannot save an Excel file for you, so use Copy for Excel and paste.
